# analyze_full_path：补路径

需要路径的类别（见 `pack.pathRequiredKinds`）证实后，要把利用链写完整：

`source`（攻击者能控制的输入）→ `transform`（解析、拼接、编码）→ `control`（校验、转义、鉴权，有就写，包括被绕过的）→ `sink`（敏感操作）。

- 每步一个定位；读不到的那一步（框架内部、依赖的黑盒）写 `gap` 和理由，不要编一个位置。
- 至少一个 `source`、一个 `sink`。
- `prerequisites` 写成立需要的前提：普通用户可登录、模板可写、某个开关打开。
- 评级的理由应当能从路径上看出来：攻击者需要什么、能拿到什么。
